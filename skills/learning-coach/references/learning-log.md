# Progress file

Keep one file per subject, `learning-log.md`, in the learner's working folder. Read it at the start of every session and update it at the end. It is the only memory between sessions.

```markdown
# Learning log: <subject>

Goal: <what the learner wants to be able to do, and by when>
Schedule: <sessions per week and usual length>
Current level: <1-6, name>
Pass criteria for this level: <from levels.md, made specific to the subject>

## Review due
| Material | Next review | Last result |
|---|---|---|

## Sessions
| Date | Level | Minutes | Predicted score | Actual score | Errors and why |
|---|---|---|---|---|---|

## Checks
| Date | Level | Score | Gaps named | Passed? |
|---|---|---|---|---|
```

One row per session. No row means it didn't happen.
